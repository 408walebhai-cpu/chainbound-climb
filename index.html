An original 2D chained co-op climb inspired by the hell-to-heaven ascent idea: rise from ember depths to bright skies — together, or drag each other down. No assets from any commercial game are used.

🎮 Controls

Phone: ◀ ▶ move, JUMP (hold for higher feel), PULL to brace and haul your dangling partner up.
Keyboard P1: A/D + W  •  P2: ←/→ + ↑  •  Pull: S / ↓  •  Restart: R

🏁 Modes

Level: reach the golden flag at the summit. Checkpoints every ~15 platforms revive you if you both fall.
Endless: climb as high as you can — fall below the camera and the run ends. Score = metres.

⛓️ Chain tips

The chain has a max length and real sag/tension. If your partner dangles, stand firm and hold PULL. Don't jump apart at the same time on narrow platforms!

Chainbound Climb is an original fan-inspired prototype. GitHub Pages hosts these static files; GitHub Actions deploys them. Phone↔host traffic uses WebRTC via the free public PeerJS broker (with a same-browser BroadcastChannel fallback) — no game server is run by GitHub. If the broker is unreachable, keyboard play still works fully.
